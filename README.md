# Async Labs Website Conversion UI/UX

**Candidate:** Pandey Khushi

## What I Built

A conversion-focused landing page for Async Labs' 7.5-inch smart workspace display.

I explored two distinct hero concepts and developed one direction into a high-fidelity desktop and mobile experience. The final design focuses on making important work information visible in the physical workspace without competing with the user's main screen.
